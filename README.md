## 📖 About

Naija Study Hub Tech is a dedicated educational platform created for Nigerian students seeking accessible, high-quality learning materials. The platform provides structured educational content covering various subjects, comprehensive study guides, and interactive resources to support academic excellence.

### Vision
To democratize quality education across Nigeria by providing free, accessible, and comprehensive learning resources tailored to the Nigerian educational curriculum.

### Mission
Empower every Nigerian student with the tools, resources, and knowledge they need to succeed academically and professionally.

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- No additional installations required

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/yunusazaharaddi/NAIJASTUDYHUBTECH.git
cd NAIJASTUDYHUBTECH
```

2. **Open in browser**
```bash
# Simply open index.html in your preferred browser
open index.html
# or
start index.html
```

3. **Or use a local server** (recommended)
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (http-server)
npx http-server
```

Then navigate to `http://localhost:8000`

## 🔧 Troubleshooting

### Common Issues

**Issue: Page not loading**
- Solution: Clear browser cache (Ctrl+Shift+Delete)
- Try a different browser
- Check internet connection
- Disable browser extensions

**Issue: Content not displaying properly**
- Solution: Update your browser to the latest version
- Clear browser cookies
- Try incognito/private mode
- Use a different device to test

**Issue: Videos not playing**
- Solution: Check internet speed (requires 2+ Mbps)
- Update video player plugins
- Try a different browser
- Disable adblockers temporarily

**Issue: Slow performance**
- Solution: Close unnecessary tabs/programs
- Clear browser cache
- Check internet speed
- Use WiFi instead of mobile data
- Try during off-peak hours

**Issue: Can't find specific content**
- Solution: Use the search function (coming soon)
- Check the sitemap
- Browse by category
- Contact support

### Getting Help
If you encounter issues not listed above:
1. Check this FAQ first
2. Search GitHub Issues
3. Contact support team
4. Open a new GitHub Issue with details
