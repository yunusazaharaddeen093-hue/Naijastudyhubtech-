# Naija Study Hub Tech

**Naija Study Hub Tech** is a free educational blog and content platform built to help Nigerian students learn key subjects through simple, well-explained articles — covering everything from English grammar to civic education and mathematics.

---

## 📚 About

Naija Study Hub Tech is a platform designed to support students' learning journey by providing clear, accessible study content on core subjects taught in Nigerian schools. Whether you're revising for exams or just trying to understand a tricky topic, our goal is to make learning simple and stress-free.

---

## ✨ Features

- 📖 **Study Articles** — In-depth lessons on subjects like English, Civic Education, and Mathematics
- 🏫 **Curriculum-Aligned Content** — Topics based on what Nigerian students actually study in school
- 📱 **Mobile-Friendly Design** — Easy to read on any device
- 🔍 **Simple Navigation** — Find what you need quickly
- 🆓 **Completely Free** — No paywalls, no sign-ups required

## 🚀 Getting Started

### Prerequisites
No special tools are required — this is a static site. You just need a web browser to view it locally, or a code editor (like VS Code) if you want to contribute.

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/Naijastudyhubtech-.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Naijastudyhubtech-
   ```
3. Open `index.html` in your browser, or use a live server extension in VS Code for the best experience.

## 🤝 Contributing

Contributions are welcome! If you'd like to add a new study topic, fix a bug, or improve existing content:

1. Fork this repository
2. Create a new branch:
   ```bash
   git checkout -b feature/your-topic-name
   ```
3. Make your changes
4. Commit your changes:
   ```bash
   git commit -m "Add: [topic/feature description]"
   ```
5. Push to your branch:
   ```bash
   git push origin feature/your-topic-name
   ```
6. Open a Pull Request describing your changes

### Content Guidelines
- Keep explanations simple and student-friendly
- Use examples relevant to the Nigerian curriculum where possible
- Match the existing HTML structure and styling for consistency
